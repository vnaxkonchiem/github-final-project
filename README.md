# Simple Interest Calculator

A simple command-line program written in Python to calculate the simple interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest ($SI$) is calculated with the following formula:

$$SI = \frac{P \times R \times T}{100}$$

Where:
* **P** = Principal amount (the initial amount of money)
* **R** = Annual interest rate (in percentage)
* **T** = Time period (in years)

---

## Features
* Calculates simple interest quickly and accurately.
* Easy-to-use Python script.
* Includes total amount calculation ($Principal + Interest$).
